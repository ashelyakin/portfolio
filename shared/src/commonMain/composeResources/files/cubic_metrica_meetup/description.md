# Cubic Metrica: доработка системы компьютерного зрения для анализа аудитории

Выступление о развитии Cubic Metrica — Android-приложения, работающего в паре с плеером Cubic Vision и определяющего характеристики аудитории перед экраном с помощью компьютерного зрения.

## О чём рассказал

**Система.** Cubic Metrica определяет пол, возраст и эмоции людей в кадре камеры (в том числе с функцией faceId для распознавания повторных появлений человека), передаёт данные плееру, а тот адаптирует показываемый контент и собирает статистику. Параметры целевой аудитории для контента задаются в CMS Cubic Vision.

**Бизнес-задача.** Показал, зачем понадобилось расширение функционала: рекламодателям нужна была точная статистика по количеству людей и составу аудитории по часам и суткам — чтобы платить не за показы, а за реальные просмотры, и дифференцировать стоимость рекламы по проходимости экрана. Разобрал прикладные кейсы использования такой статистики (сравнение экранов в разных локациях, таргетинг рекламы по демографии) и объяснил, чем данные Cubic Metrica точнее сторонних источников (например, геостатистики от агрегаторов), поскольку считают фактическое число людей в конкретной точке, а не усреднённые данные по адресу.

**Технические доработки.** Для решения поставленных задач потребовалось:
- **Переработать интерфейс** — перешёл с XML View на декларативный Jetpack Compose, связав настройки из Shared Preferences напрямую с UI для изменения параметров в реальном времени без перезапуска приложения.
- **Изменить архитектуру приложения** — устранил проблему двойного управления жизненным циклом камеры между Activity и Service (lifecycleOwner), сделав единственным владельцем жизненного цикла сервис. Это устранило необходимость перепривязки компонентов при открытии/закрытии интерфейса и заодно решило проблему автозапуска приложения при загрузке устройства без конфликта с Cubic Vision.
- **Оптимизировать модель распознавания пол-возраст** — совместно с ЮГПА провёл исследование производительности разных нейросетевых архитектур на CPU и GPU целевых устройств. В результате среднее время обработки кадра снизилось с 60 до 21 мс на CPU и с 68 до 40 мс на GPU; итоговая модель реализована на архитектуре MobileNetV4.
- **Добавить управление из CMS** — реализовал управление параметрами Cubic Metrica (статус анализатора, включение моделей эмоций/faceId, адрес и порт подключения) через плеер, для чего перевёл взаимодействие плеера и Cubic Metrica с TCP на WebSocket.
- **Реализовать новую модель подсчёта людей** — так как существующие модели распознают только лица (и пропускают людей, чьё лицо не попало в кадр), интегрировал отдельную модель детекции (bounding box) и реализовал трекинг объектов между кадрами через алгоритм ByteTrack (интегрирован на C++ через Java Native Interface в проект на Kotlin).

**Побочный эффект.** Переход на WebSocket также открыл возможность подключать внешние демонстрационные и аналитические приложения к Cubic Metrica по локальной сети — один из членов команды реализовал такое приложение для просмотра статистики.

## Демонстрация и результаты

Доклад сопровождался демонстрацией работы приложения в эмуляторе. Также была решена недавняя проблема с ограничением Android на доступ к камере из фонового процесса — запуск фонового процесса Cubic Metrica теперь инициируется из Cubic Vision, что обходит новое требование системы без конфликта прав между приложениями.
