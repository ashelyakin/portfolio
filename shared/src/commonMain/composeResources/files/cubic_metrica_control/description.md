# Cubic Metrica Control

Android-приложение для прямого подключения к Cubic Metrica по локальной сети. Оно
показывает результаты распознавания в реальном времени и позволяет управлять
трекером удалённо — служит инструментом отладки на объекте и наглядной
демонстрацией возможностей системы.

Приложение я показывал в докладе на техническом митапе как пример того, как
открытый протокол Cubic Metrica позволяет строить вокруг неё внешние клиенты.

---

## Контекст и задача

После того как взаимодействие Cubic Metrica с внешним миром было переведено на
WebSocket, к трекеру смог подключиться любой клиент в локальной сети. Это открыло
возможность, которой раньше не было: наблюдать за работой распознавания со стороны,
не подключаясь к самому устройству с камерой.

Потребность была практическая. Чтобы проверить данные от Cubic Metrica необходимо собрать отчеты через систему Cubic Vision.
Это неудобно и затратно по времени для оперативной отладки и не подходит для live демонстрации работы.
Cubic Metrica Control закрывает обе задачи — отладку при установке и демонстрацию продукта.

## Ключевые результаты

Проект я создал полностью самостоятельно — от идеи и протокола взаимодействия до
итогового приложения.

### Реализовал мониторинг распознавания в реальном времени

Главный экран показывает поток данных от трекера по мере их поступления: сколько
людей сейчас в кадре, сколько прошло за сеанс, сколько из них смотрят на экран.
Ниже — разбивка аудитории по полу и по возрастным группам, показатель внимания к
экрану и список обнаруженных людей с их характеристиками. Отдельный раздел
накапливает статистику за период.

Это делает работу моделей наблюдаемой: видно не только итоговые цифры, но и то, как
трекер интерпретирует конкретную сцену перед камерой.

### Добавил удалённое управление трекером

Приложение подключается к Метрике по IP-адресу и порту, показывает статус
соединения и версию установленного трекера, умеет переподключаться автоматически при
запуске. Из панели управления включаются и отключаются отдельные модели —
аналитика, эмоции, Face ID — то есть те же параметры, что доступны из CMS, но без
обращения к ней.

На объекте это сокращает цикл проверки до нескольких секунд: можно на месте
переключить конфигурацию и сразу увидеть, как изменилось поведение распознавания.

### Собрал приложение с помощью Claude Code

Приложение целиком сгенерировано в связке с Claude Code. Моя роль здесь —
проектирование: я задавал структуру экранов, формат обмена с трекером и логику
агрегации данных, а затем проверял и правил результат. Такой подход позволил
получить рабочий инструмент за считанные дни вместо недель.
